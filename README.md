# CampusShield 🛡️

## AI-Powered Campus Cybersecurity Assistant

CampusShield is a student-friendly cybersecurity assistant designed to help students identify suspicious links, phishing attempts, fake QR codes, and online scams.

## Problem

College students frequently encounter phishing links, fake QR codes, impersonation messages, and other online scams. Many students do not have enough technical knowledge to identify these threats.

## Solution

CampusShield analyzes suspicious digital content and provides a simple risk assessment with understandable explanations.

## Planned Features

- 🔗 Suspicious URL analysis
- 📱 QR code analysis
- 💬 Phishing message analysis
- ⚠️ Risk assessment
- 🛡️ Security recommendations
- 🚨 Campus scam alerts
